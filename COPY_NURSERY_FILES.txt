================================================================================
TROUBLESHOOTING:
================================================================================

If you get errors:

1. "Table doesn't exist"
   → Run the nursery_schema.sql file in phpMyAdmin

2. "No nurseries in dropdown"
   → Create Business Units with unit_type = 'Nursery'

3. "No varieties available"
   → Create plant varieties in Plant Varieties module

4. "Permission denied"
   → Check file permissions, ensure XAMPP has read access

5. "Page not found"
   → Verify files are in correct location: C:\xampp\htdocs\plantation_master\
